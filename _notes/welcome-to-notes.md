이 파일(`_notes/welcome-to-notes.md`)은 **예시 노트**입니다. 새 노트를 쓰고 싶을 때는:

1. `_notes/` 폴더 안에 새 `.md` 파일을 만듭니다. 파일 이름은 영문/숫자/하이픈만 사용하세요. (예: `_notes/additive-manufacturing-review.md`)
2. 아래처럼 맨 위에 front matter(메타 정보)를 채웁니다.
3. 그 아래에 마크다운으로 본문을 자유롭게 씁니다.
4. GitHub에 커밋하면 `/notes/` 목록에 자동으로 추가됩니다. **index.html이나 다른 파일은 건드릴 필요 없습니다.**

## Front matter 항목 설명

```yaml
---
title: "노트 제목"              # 필수
date: 2026-10-08                # 필수, 정렬 기준이 됩니다 (최신순)
category: "Lab Notes"           # 선택, 목록 페이지의 필터 버튼이 이 값으로 자동 생성됩니다
tags: [태그1, 태그2]             # 선택, 상세 페이지에 배지로 표시되고 검색 대상이 됩니다
excerpt: "목록에 보여줄 1~2문장 요약"  # 선택
paper_title: "관련 논문 제목"     # 선택
paper_url: "https://..."        # 선택, paper_title과 함께 링크로 표시됩니다
---
```

## 마크다운 작성 팁

- `## 제목`, `### 소제목`으로 섹션을 나눌 수 있습니다.
- `**굵게**`, `*기울임*`, `[링크 텍스트](https://example.com)` 문법을 그대로 쓸 수 있습니다.
- 목록도 지원됩니다:
  - 첫 번째 항목
  - 두 번째 항목
- 인용문:

  > 이렇게 인용 블록을 넣을 수도 있습니다.

- 코드도 깔끔하게 표시됩니다:

```python
def hello():
    print("Hello, Green Design Lab!")
```

새 노트를 쓰실 때는 이 파일을 복사한 뒤, 내용만 지우고 위 안내에 따라 채워 넣으시면 됩니다.
